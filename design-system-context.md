# Design system rollout context

- The requested direction is a reliable, heavyweight fight-board aesthetic: near-black surfaces, assertive Korean type, restrained red for fight-critical information, and yellow only for rankings or title status.
- Fighter photos already have an acceptable scale. The implementation will preserve their present proportions except for a small reduction in the largest home hero photos to make room for verified event and fighter metadata.
- The work is limited to the existing visual system and will not change event data, collection schedules, or feature behavior.
